# Navigation bar icons

Copy your 5 tab icons into this folder with these exact names:

| Your file            | Save as            |
|----------------------|--------------------|
| homescreen_tab_icon  | nav_home.png       |
| community_tab_icon   | nav_community.png  |
| shoppingcart_tab_icon| nav_cart.png       |
| fridge_tab_icon      | nav_fridge.png     |
| profile_tab_icon     | nav_profile.png    |

The app will tint them grey when unselected and orange with a circle when selected. Use 72×72 px (or 24/48/72 for 1x/2x/3x) for best quality.
